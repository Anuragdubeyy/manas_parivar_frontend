## 🌼 Project Overview

This **Jap Counter Web Application** is developed to help spiritual communities maintain a collective count of jap recitations performed by their followers.  
Devotees can register, log in, select their jap type, and record their jap count with ease.

This platform assists organizations in achieving their **Jap Sankalp** goals by aggregating the total jap from all users.

---

## ✨ Key Features

### 👤 **User Authentication**
- User registration & secure login  
- Role-based access (if required for admins)

### 📿 **Pre-Set Jap Options**
Includes commonly recited japs:
- *"राम राम माला"*  
- *"ॐ नमः शिवाय"*  
- *"हनुमान चालीसा"*  
- And more…  

Users can also add their own custom jap entries.

### 🔢 **Jap Counter System**
- Users can enter jap counts  
- **Auto-conversion:**  
  - **108 Nam-Japs = 1 Mala**  
- Automatic record updates  
- Jap history stored per user

### 📊 **Organization-Wide Jap Dashboard**
- Total jap from all followers  
- Helps achieve collective **Sankalp goals**

### 🧘 **Simple, Spiritual & Clean UI**
- Minimal, peaceful interface  
- Optimized for mobile and desktop
